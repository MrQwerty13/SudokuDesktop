# Card.md — Продуктовая карточка Sudoku Desktop

## 1. Идентификация

| Поле | Значение |
|---|---|
| Название | Sudoku Desktop |
| Тип | Одиночная офлайн-игра (desktop) |
| Платформы | macOS, Linux, Windows (x64; macOS — x64 + arm64) |
| Язык | C# / .NET 10 / Avalonia UI 12 |
| Лицензия | Не определена — требует решения владельца |
| Статус | Этап 1: каркас решения собран (4 проекта в `src/` + 4 тестовых в `tests/`), игровой логики нет |

## 2. Назначение и ценность

Дать офлайн-игру «собери/реши судоку» без аккаунтов, рекламы и сетевых зависимостей.
Пользователь открывает приложение, выбирает режим и сложность, решает головоломки,
при необходимости получает подсказку, прогресс переживает перезапуск приложения.

## 3. Целевая аудитория

- Casual-игроки, играющие в sudoku в поездках, самолёте, в зонах без сети.
- Люди, ценящие «открыл и играешь» без регистрации и рекламы.
- Не требуется (и не планируется) соревновательный онлайн-режим.

## 4. Ключевые продуктовые решения (зафиксировано)

1. **Полностью офлайн.** Никаких сетевых запросов, телеметрии, аккаунтов и автообновлений.
2. **Три уровня сложности:** Easy, Normal, Hard.
3. **Подсказки неограниченные.** Подсказка всегда доступна, но её использование фиксируется.
4. **Endless** — неограниченное число судоку, без таймера.
5. **Time Attack** — фиксированный лимит времени:
   - 1 судоку → 10 минут
   - 2 судоку → 20 минут
   - 3 судоку → 30 минут

## 6. Ограничения

- **Офлайн.** Генерация и ранжирование головоломок выполняются локально, без обращения к API.
- **Детерминизм.** Один и тот же seed → одна и та же головоломка (нужно для тестов и повторяемости).
- **Скорость генерации.** Генерация головоломки не должна блокировать UI дольше ~1 с.
- **Уникальность.** У каждой выданной головоломки ровно одно решение.
- **Целевые ОС:** macOS 14+ (нативно), Ubuntu 25.x / Debian 13 / Fedora 43 (Tier 1),
  Windows 11 24H2+ (Tier 1). Дистрибутивы Tier 3 (Alpine/musl, NixOS) — вне объёма.
- **Никакой сетевой активности** в рантайме, включая проверку обновлений.

## 7. Риски (продуктовые)

| Риск | Влияние | Митигация (предложена) |
|---|---|---|
| Оценка сложности субъективна | Пользователь не получает ожидаемую «сложность» | Рейтинг по потолку техник + secondary-метрика; см. ADR-0003 |
| Генерация Hard-головоломок медленная | Задержка при старте | Банк заранее сгенерированных головоломок + рандомизация перестановками |
| Time Attack: неясна семантика «2 судоку за 20 минут» | Разные ожидания пользователя | Требует решения владельца — см. §8 |
| Отсутствие код-подписи на macOS/Windows | Предупреждения SmartScreen/Gatekeeper | Требует решения владельца — см. §8 |

## 8. Открытые продуктовые вопросы (требуют решения владельца)

1. **Time Attack: таймер на весь заход или на каждый судоку?**
   Предлагается: единый таймер на весь заход (10/20/30 минут суммарно на 1/2/3 головоломки).
2. **Что происходит при истечении времени?**
   Варианты: конец захода с сохранением прогресса / завершение текущей головоломки с обнулением таймера /
   штраф за каждую оставшуюся нерешённую головоломку.
3. **Начисление бонуса за решённые головоломки в Time Attack?**
4. **Продолжается ли таймер, пока окно свёрнуто / приложение в фоне?**
   Предлагается: таймер идёт по реальному времени (пауза только по явному действию пользователя).
5. **Разрешена ли пауза в Time Attack?** Если да — сколько раз и как долго?
6. **Как подсказки влияют на счёт/статистику?** Штраф за подсказку, лимит подсказок на головоломку,
   счёт в Time Attack — сейчас подсказки неограниченные, влияние не задано.
7. **Отдельные счётчики по сложностям или общий?** Нужна ли таблица рекордов по режимам?
8. **Сохраняется ли статистика (число решённых, время, серии) между запусками?** Требует ли выгрузка/сброс?
9. **Нужен ли «Daily Puzzle» (одна и та же головоломка в день)?** В текущем ТЗ отсутствует.
10. **Нужна ли локализация (RU/EN)?** Текст интерфейса на английском — по умолчанию.
11. **Целевая аудитория/возраст и визуальный стиль:** минималистичный материалный дизайн
    или крупные кнопки/высокий контраст для accessibility?
12. **Поддержка ввода с клавиатуры:** навигация стрелками, ввод цифр, удаление — обязательна или нет?
13. **Разрешена ли одновременная игра в двух окнах?** (влияет на путь хранения состояния)
14. **Нужна ли поддержка Wayland на Linux?** Нативный Wayland-бэкенд Avalonia 12.1 — опциональный
    и не имеет авто-фолбэка; по умолчанию работает XWayland.
15. **Модель лицензирования и распространения:** freeware / open source / платное; нужна ли лицензия
    сторонних наборов головоломок.
16. **Нужна ли подпись и нотарификация сборок?** Для macOS требуется платная подписка Apple Developer ID.
17. **Формат дистрибутива для Windows:** MSIX, NSIS-инсталлятор, portable ZIP.
18. **Формат дистрибутива для Linux:** `.deb`, `.rpm`, AppImage, Flatpak.
19. **Avalonia Plus Developer Tools:** пакет `AvaloniaUI.DiagnosticsSupport` оставлен только для
    Debug-сборок. Инструмент Developer Tools — коммерческий продукт Avalonia Plus:
    подтвердите, что его использование приемлемо для планируемой модели лицензирования (п. 15).

## 9. Критерии готовности продукта (Release 1.0)

- Все FR из [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) со статусом «обязательное» выполнены.
- Три сложности выдают головоломки с уникальным решением и повторяемым рейтингом.
- Endless и Time Attack работают на всех трёх ОС, состояние переживает перезапуск.
- Сборка публикуется и запускается на macOS, Linux и Windows.
- Нет сетевых обращений (проверяется тестом/аудитом зависимостей).

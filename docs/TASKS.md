## Этап 3. Решатель и проверка уникальности — ✅ Завершён

**Цель:** движок решения, на котором строятся генерация, рейтинг и подсказки.

**Содержание**

- [x] `MrvSudokuSolver`: битовые маски кандидатов, constraint propagation (naked single,
      hidden single), DFS с выбором ячейки по MRV
- [x] `Solve(grid)` → результат с видом решения и найденными вариантами
- [x] `CountSolutions(grid, limit)` → подсчёт решений с остановкой на заданном пределе
- [x] `SolveResult` / `SolveOutcome`: `NoSolution` / `UniqueSolution` / `MultipleSolutions`
- [x] `ISudokuSolver` — абстракция решателя в `Sudoku.Application`
- [x] Откат состояния через стек назначений; исходный `Grid` не мутируется
- [x] Обработка некорректного ввода: `null`, неверная длина/символы строки, предел < 1,
      противоречивые заданные цифры
- [x] Тесты: известная решаемая головоломка; головоломка без решения; головоломка с
      несколькими решениями; уже решённая сетка; некорректный ввод; неизменность входа;
      детерминизм; предел поиска
- [x] Независимые тестовые данные (опубликованная головоломка и её решение; неоднозначная
      головоломка, построенная из опубликованного решения)
- [x] ADR-0008 «Решатель судоку: битовые маски, распространение ограничений и MRV»

**Критерии завершения**

- Известная решаемая головоломка решается и совпадает с опубликованным решением — ✅
- `CountSolutions` находит ровно 2 решения там, где их два, и останавливается на пределе — ✅
- Головоломка без решения распознаётся как `NoSolution` — ✅
- Время решения обычной головоломки — порядка единиц миллисекунд (запас многократно
  превышает требование NFR-05) — ✅

**Примечание.** Эталонный набор из 50 головоломок формата Project Euler #96 (собственный
файл) перенесён в этап 4 вместе с генератором: собственный набор потребуется для проверки
генератора, а не только решателя.

## Этап 4. Генератор и рейтинг сложности (v1) — ⬜ Не начато

**Цель:** выдавать головоломки Easy / Normal / Hard с уникальным решением и воспроизводимым рейтингом.

**Содержание**

- [ ] `PuzzleGenerator`: полное заполнение → удаление подсказок с проверкой уникальности → стоп по рейтингу
- [ ] `IDifficultyRater` (v1): потолок техник — naked single, hidden single, pointing/claiming, naked/hidden pair
- [ ] Сопоставление оценок с категориями Easy / Normal / Hard (калибровочные пороги)
- [ ] `IRandomSource` — инъекция источника случайности с seed
- [ ] Тесты: уникальность (1000 генераций), детерминизм по seed, попадание в категорию (≥ 95 %),
      попадание в целевой диапазон времени генерации

**Критерии завершения**

- ≥ 1000 сгенерированных головоломок, у всех ровно одно решение
- Один и тот же seed → побайтово одинаковая головоломка
- ≥ 95 % генераций попадают в заявленную категорию сложности
- Генерация Easy/Normal < 1 с, Hard < 5 с

**Риск:** калибровка порогов «нормальная/сложная» может потребовать итераций — это ожидаемо.

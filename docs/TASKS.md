## Этап 3. Решатель и проверка уникальности — ⬜ Не начато

**Цель:** движок решения, на котором строятся генерация, рейтинг и подсказки.

**Содержание**

- [ ] `MrvSudokuSolver`: битовые маски кандидатов, constraint propagation, DFS с выбором по MRV
- [ ] `Solve(grid)` → единственное решение
- [ ] `CountSolutions(grid, limit: 2)` → проверка уникальности
- [ ] `Step(grid)` — пошаговое применение простейшей техники (для подсказок), с объяснением
- [ ] Эталонный набор из 50 головоломок формата Project Euler #96 (собственный файл, без копирования
      текста с CC BY-NC-SA)
- [ ] Тесты: корректность на эталонном наборе; детерминизм; граничные случаи (пустая доска,
      неразрешимая доска, несколько решений)

**Критерии завершения**

- 50/50 эталонных головоломок решаются корректно
- `CountSolutions` находит ровно 2 решения там, где их два
- Время решения одной головоломки < 50 мс в среднем (замер в тесте-договоре, не жёсткий assert)

## Этап 4. Генератор и рейтинг сложности (v1) — ⬜ Не начато

**Цель:** выдавать головоломки Easy / Normal / Hard с уникальным решением и воспроизводимым рейтингом.

**Содержание**

- [ ] `PuzzleGenerator`: полное заполнение → удаление подсказок с проверкой уникальности → стоп по рейтингу
- [ ] `IDifficultyRater` (v1): потолок техник — naked single, hidden single, pointing/claiming, naked/hidden pair
- [ ] Сопоставление оценок с категориями Easy / Normal / Hard (калибровочные пороги)
- [ ] `IRandomSource` — инъекция источника случайности с seed
- [ ] Тесты: уникальность (1000 генераций), детерминизм по seed, попадание в категорию (≥ 95 %),
      попадание в целевой диапазон времени генерации

**Критерии завершения**

- ≥ 1000 сгенерированных головоломок, у всех ровно одно решение
- Один и тот же seed → побайтово одинаковая головоломка
- ≥ 95 % генераций попадают в заявленную категорию сложности
- Генерация Easy/Normal < 1 с, Hard < 5 с

**Риск:** калибровка порогов «нормальная/сложная» может потребовать итераций — это ожидаемо.

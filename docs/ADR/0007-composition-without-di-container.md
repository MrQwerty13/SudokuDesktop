# ADR-0007. Композиция зависимостей без DI-контейнера на этапе 1

- **Статус:** Принято
- **Дата:** 2026-11-13
- **Связано с:** [ADR-0006](0006-domain-application-projects.md)

## Контекст

Требование владельца к этапу 1: «Настрой dependency injection только там, где он действительно нужен».

На этапе 1 в приложении нет ни одного сервиса, требующего внедрения: домен содержит
перечисления, Application — один объект опций (`GameOptions`), UI создаёт ViewModel напрямую.
Подключение контейнера (`Microsoft.Extensions.DependencyInjection`) в такой ситуации:

- добавит внешнюю зависимость и NuGet-пакет без единого сценария использования;
- потребует настройки lifetime, области видимости и композиционного корня раньше, чем
  появится хотя бы один внедряемый сервис;
- усложнит сборку и тесты без выигрыша.

## Решение

**DI-контейнер на этапе 1 не подключается.**

- `Sudoku.App` создаёт объекты напрямую: `new MainWindowViewModel(GameOptions.Default)`.
- Внедрение зависимостей выполняется через конструкторы (обычные C#-параметры), что уже
  является формой DI и позволяет подставлять тестовые doubles без контейнера.
- Пакет `Microsoft.Extensions.DependencyInjection` **не добавляется** в `Directory.Packages.props`.

Когда появится первый реальный сервис (этап 6 — `IStateStore`/`IAppPaths`, этап 7 — навигация),
будет принято отдельное решение: контейнер в `Sudoku.App` как композиционный корень
или ручная сборка графа в `App.OnFrameworkInitializationCompleted`.

## Последствия

**Положительные**
- Нет лишних зависимостей и лишней абстракции.
- Состав приложения видно прямо в коде: `App.axaml.cs` — единственное место, где
  создаются объекты Presentation-слоя.
- Миграция на контейнер позже — локальная правка композиционного корня, а не переработка
  кода слоёв.

**Отрицательные**
- При росте числа сервисов ручная сборка графа станет многословной.
- Пока нет контейнера, неявные зависимости (создание объектов внутри методов) легче
  допустить по невнимательности — компенсируется ревью по правилам слоёв (AGENTS.md, §4).

## Альтернативы

| Вариант | Оценка |
|---|---|
| **Подключить `Microsoft.Extensions.DependencyInjection` сразу** | Отклонён: контейнер без сервисов — преждевременная абстракция |
| **Autofac / DryIoc / SimpleInjector** | Отклонён: сторонние зависимости без потребности |
| **Ручное создание объектов (выбрано)** | При текущем масштабе — достаточно; переход на контейнер возможен без изменения слоёв |
| **Service Locator** | Отклонён: скрывает зависимости, ухудшает тестируемость |

# ADR-0003. Оценка сложности: потолок техник + вторичная метрика

- **Статус:** Принято
- **Дата:** 2026-11-13
- **Связано с:** [ADR-0002](0002-project-and-layer-structure.md)

## Контекст

Продукт требует три уровня сложности (Easy / Normal / Hard). Ключевой технический риск —
как гарантировать, что выданная головоломка действительно соответствует заявленной сложности.

Исследование показало:

1. **Единого стандарта сложности не существует.** Оценки разных инструментов
   (Sudoku Explainer, HoDoKu, xSudoku, Sudoku Exchange) не совпадают; даже
   «простейший путь решения» неоднозначен. (Архив FAQ Дюфурского университета,
   https://web.archive.org/web/2012/http://diuf.unifr.ch/people/juillera/Sudoku/FAQ.html)
2. **Число подсказок — слабый признак сложности.** Корреляция «число заданных значений»
   с человеческой сложностью ≈ 0.25 по данным Pelánek et al.
   (https://arxiv.org/abs/1403.7373). Публикация Sudoku Pulse приводит прямой контрпример:
   Medium в NYT (23–26 подсказок) сложнее, чем Expert на sudoku.com (30–32).
   (https://sudokupulse.com/articles/sudoku-difficulty/)
3. **Устойчивая метрика — потолок техник** (technique ceiling): максимальная сложность
   приёма, необходимого для решения без угадывания. Используется в Sudoku Explainer
   (рейтинги 1.0–11.9+), HoDoKu (взвешенная сумма техник), xSudoku (8 уровней).
4. **Вторичная метрика — «нужно ли угадывание»**: доля решений, достигаемых логикой
   без перебора (в терминах tdoku — `%no_guess`), и глубина дерева поиска.
   (https://github.com/t-dillon/tdoku)
5. Оценка по времени решения решателя **непригодна**: она зависит от порядка перебора
   значений — разброс между 190 с и 0.02 с на одном и том же наборе (Norvig,
   https://norvig.com/sudoku.html).

Дополнительно: минимальное число подсказок для уникальности — 17 (McGuire, Tugemann,
Civario, 2012, https://arxiv.org/pdf/1201.0749); при этом большинство «средних»
головоломок имеют 22–32 подсказки.

## Решение

**Двухуровневая метрика сложности с эскалацией по этапам.**

### Уровень v1 (этап 4) — обязательный

`IDifficultyRater` возвращает:
- `TechniqueCeiling` — максимальный ранг применённой техники;
- `SearchDepth` / `GuessCount` — вторичная метрика (требуется ли перебор).

Лестница техник v1 (по возрастанию сложности):
naked single → hidden single → pointing pair → claiming pair → naked pair → hidden pair.

Калибровка: пороги Easy / Normal / Hard подбираются эмпирически по сгенерированной
выборке (≥ 1000 головоломок на категорию) и фиксируются в тесте как константы
(регрессия от «переезда» порогов ломает тесты).

Дополнительный критерий приёмки головоломки в категорию Hard: решается **только**
логическими техниками (без перебора) и потолок не ниже заданного.

### Уровень v2 (этап 5) — по решению владельца

Расширение лестницы: X-Wing, Swordfish, XY-Wing, базовые цепочки (forcing chains).
Требуется, если на практике окажется, что v1 не различает «нормальную» и «сложную»
головоломки достаточно выразительно.

### Fallback (этап 5/12) — опционально

Предсгенерированный банк головоломок с независимой оценкой сложности:
[grantm/sudoku-exchange-puzzle-bank](https://github.com/grantm/sudoku-exchange-puzzle-bank) —
**public domain**, формат компактный (SHA1 + 81 цифра + рейтинг), рейтинги получены
Sukaku Explainer v1.2.1. Рандомизация перестановками цифр/строк/столбцов даёт визуально
свежие головоломки с сохранением сложности.

> Лицензионное ограничение: набор Project Euler #96 распространяется по CC BY-NC-SA —
> использовать в коммерческом приложении нельзя. Используется **только** как
> некоммерческий эталон в тестах либо перегенерируется собственным генератором.

## Последствия

**Положительные**
- Рейтинг объясним: можно показать игроку, какое правило потребовалось, и то же самое
  используется для подсказок (единый движок).
- Детерминирован и воспроизводим: зависит только от состояния доски.
- Реализация v1 — небольшой объём (несколько сотен строк), полностью тестируема.

**Отрицательные**
- «Правильная» сложность — субъективная величина; калибровку придётся подтверждать
  на живых пользователях, а не только на тестах.
- v1 может не выделять достаточно тонких градаций внутри Hard ⇒ потребуется v2.
- Внешний банк головоломок вносит зависимость от чужого рейтинга: при смене версии
  Sukaku Explainer калибровка «поедет» (нужно хранить версию рейтинга рядом с головоломкой).

## Альтернативы

| Вариант | Оценка |
|---|---|
| **Только число подсказок** | Отклонён: корреляция ≈ 0.25, Easy и Hard неразличимы |
| **Время решения машинного решателя** | Отклонён: зависит от порядка перебора, крайне нестабильно |
| **Сравнение с эталонными решателями (branch count, Beer)** | Отклонён как основной критерий (не про человека), оставлен как вторичная метрика |
| **Оценка по среднему времени человека** | Отклонён: нет достоверных данных в проекте, дорого в разработке |
| **Полная лестница техник сразу (v2 = v1)** | Отклонён: заметно больший объём без подтверждения, что он нужен |
| **Только внешний банк, без своего рейтинга** | Отклонён: нельзя генерировать бесконечные режимы и нельзя контролировать сложность on-demand |

# REQUIREMENTS.md — Sudoku Desktop

Обозначения: **FR** — функциональные требования, **NFR** — нефункциональные.
Приоритет: **M** — обязательное для Release 1.0, **S** — желательное, **O** — открыто (требует
решения владельца, см. раздел 5).

Источник истины по продуктовым решениям — [Card.md](../Card.md).

## 1. Функциональные требования

### 1.1. Головоломки и сложность

| ID | Требование | Приоритет |
|---|---|---|
| FR-01 | Приложение генерирует головоломки судоку 9×9 | M |
| FR-02 | Режимы сложности: **Easy**, **Normal**, **Hard** — ровно три, выбираются игроком | M |
| FR-03 | Каждая выданная головоломка имеет **ровно одно** решение | M |
| FR-04 | Генерация детерминирована: одинаковый `seed` → одинаковая головоломка | M |
| FR-05 | Каждая головоломка снабжена числовой оценкой сложности, попадающей в диапазон своей категории | M |
| FR-06 | Категории сложности не пересекаются: оценка Easy < Normal < Hard (на 90-м перцентиле выборок) | M |
| FR-07 | Возможность получить следующую головоломку той же сложности без перезапуска приложения | M |

> **Как реализованы FR-03…FR-06 (этап 4):** уровень головоломки определяется **потолком
> логических приёмов**, а не числом пустых клеток: Easy — потолок 1–2 (одиночные приёмы),
> Normal — 3–4 (указывающие и заявляющие пары), Hard — 5–6 (голые и скрытые пары).
> Каждая выданная головоломка имеет ровно одно решение (проверяется решателем при генерации),
> а её оценка пересчитывается независимо перед выдачей: несоответствующая уровню
> головоломка не возвращается. Алгоритм, калибровка и измеренные ограничения —
> [ADR-0009](ADR/0009-puzzle-generation-algorithm.md).

## 3. Ограничения предметной области

- Правило судоку: в каждой строке, столбце и блоке 3×3 каждая цифра 1–9 встречается ровно один раз.
- Минимальное число подсказок для уникальности — 17 (доказано полным перебором, McGuire et al., 2012).
- Подсказки (given) не редактируются; редактируются только значения, введённые игроком.

## 4. Критерии приёмки (Release 1.0)

1. Все требования с приоритетом **M** реализованы и покрыты тестами.
2. На каждой из трёх ОС приложение запускается, генерирует головоломки всех трёх сложностей,
   проходит заход в Endless и Time Attack, восстанавливает состояние после перезапуска.
3. `dotnet build` — 0 warnings; `dotnet test` — все тесты зелёные.
4. Аудит зависимостей подтверждает отсутствие сетевых вызовов.
5. Опубликованы сборки для macOS (x64/arm64), Linux (x64), Windows (x64).

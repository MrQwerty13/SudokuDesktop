# Sudoku.Domain

Слой **Domain**: чистые типы предметной области судоку.

**Может зависеть только от:** BCL (`net10.0`).
**Запрещено:** Avalonia, `System.IO`, файловая система, сеть, зависимость от других слоёв.

Содержит типы, несущие смысл игры:

| Тип | Назначение |
|---|---|
| `Difficulty` | Уровни сложности: Easy, Normal, Hard |
| `GameMode` | Режимы игры: Endless, Time Attack |
| `Grid` | Доска 9×9; значение 0 = пусто; неизменяемая; разбор из строки, проверки полноты и непротиворечивости |
| `Puzzle` | Головоломка: заданные значения, решение, уровень сложности, оценка |
| `DifficultyRating` | Оценка: наличие и единственность решения, потолок приёмов, требуется ли перебор |
| `SudokuTechnique` | Лестница приёмов v1 (naked single → hidden pair) |
| `GameSession` | Состояние захода: исходное поле, текущее поле, подтверждённое решение, выбор клетки, ввод и стирание, запрет изменения исходных клеток, конфликты, подсказки по решению, победа |
| `Cell` | Снимок состояния ячейки: значение, исходная/пользовательская, конфликт, корректность |
| `CellPosition` | Позиция ячейки (строка, столбец) |
| `MoveOutcome` | Результат действия игрока: применено или отклонено |
| `HintResult` / `HintStatus` | Итог запроса подсказки |

Правила слоя закреплены тестами `Sudoku.Domain.Tests/LayerBoundaryTests.cs`.
